    Set up Model Hub

    Model Hub uses a few free tools. Install what you need; everything comes from the official sources (winget / npm). You can come back here any time from Settings.

    Windows may ask for permission while installing. Ollama starts automatically after it's installed. After installing a CLI, sign in under Settings → Accounts.

    Settings

    Accounts

    Use your own plans instead of API billing. These run each company's official CLI in a separate profile for this app. You sign in through their own sign-in page; the app never sees your password or token. Usage counts toward your plan's limits. Their own tools stay on, except the ones this app provides (shell, browser, web search, writing files), so those go through the app's approvals.

    Claude Code

    Your Claude plan (Pro, Max, Team…) via the official Claude Code CLI.

    Codex

    Your ChatGPT plan (Plus, Pro, Business…) via OpenAI's official Codex CLI.

    Gemini CLI

    Your Google account (free daily allowance, more with Google AI plans) via Google's official Gemini CLI.

    Claude API

    API key from the Claude Console. Without one, the app uses ANTHROPIC_API_KEY or an ant auth login profile. Billed per token. To use your Claude plan instead, sign in to Claude Code above.

    OpenAI API

    API key from the OpenAI platform. OPENAI_API_KEY also works. Billed per token. To use your ChatGPT plan instead, sign in to Codex above.

    Gemini API

    API key from Google AI Studio (there's a free tier). GEMINI_API_KEY also works. To use your Google account instead, sign in to Gemini CLI above.

    Ollama.com

    Links this PC's Ollama to your ollama.com account, which unlocks cloud models: very large models running on Ollama's servers (usage limits on the free plan; prompts leave your PC). Local models are unaffected.

    Hugging Face

    For gated repos (e.g. Llama, original Gemma) and private ones. Create a read token, and accept each gated model's license on its Hugging Face page.

    So Ollama can download gated models too: Ollama downloads with its own key. Add it to your Hugging Face account once (the button copies it and opens the page; paste and save).

    Keys and tokens are encrypted with Windows DPAPI and only sent to the service they belong to.
